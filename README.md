# BookStoreApp
a Java based bookstore application devloped for COE528: Object-Orinted Engineering at Toronto Metropolotian University

Overview

This project is a desktop based application that allows users to interact with a collection of books and perform common bookstore application and also a admin login to monitor operations for various users logged into the system. The application was designed using object-oriented-programming principles, with diffrent classes responsible for various aspects of the system.
